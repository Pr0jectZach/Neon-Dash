Neon-Dash!


Neon-Dash is a simple cyberpunk platformer where you jump through neon levels, collect coins, stomp enemies, and make it to the portal.


 it has 3 Levels

01 — Easy: The Grid
Wide platforms and easy jumps. A good place to get used to the game.

02 — Medium: Circuit Rush
Tighter jumps, moving platforms, and more enemies.

03 — Hard: Overload
Harder jumps, faster enemies, and a high portal. Be careful not to fall.

Controls
← / → or A / D — Move
Space or ↑ / W — Jump / Double Jump
↓ — Stomp enemies
Portal — Collect all the coins, then enter the portal
Points
Coin — +100
Enemy — +200
Level Complete — +500
Speed Run Bonus — +300
All 3 Levels — Glory + leaderboard spot

Try to collect everything, finish as fast as you can, and see how high you can get on the leaderboard.
